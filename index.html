How it works

DelTriC builds trustworthy dense seed components and grows them using original-space geometry. Projection supplies a tractable neighbourhood topology for multi-dimensional data; it does not replace the original distances used to make the clustering decisions.

Input data

Native 2-D data

Keep the input geometry

No projection: the two-dimensional input directly defines the neighbourhood topology.

↓

Build the Delaunay graph

Triangulation connects geometrically local candidate neighbours.

Multi-dimensional data

UMAP topology projection

Project to 2-D only to obtain a usable local-neighbourhood topology.

↓

Build the Delaunay graph

Triangulate the projected topology while retaining the original coordinates.

Original-space lengths remain the primary geometric signal.

↓

Use original-space edge geometry

The projected graph supplies candidate neighbours; the source-space distances evaluate whether those connections are geometrically plausible.

↓

Find dense seed components

Short, locally coherent edges form conservative cluster nuclei, using the first significant edge-length mode with a robust fallback.

↓

Grow components conservatively

Components expand round by round using their own original-space edge statistics, with a projected-space safety check when applicable.

↓

Resolve supported narrow connections

Topology-aware cuts are considered only for components whose geometry supports a meaningful split.

↓

Reassign plausible boundary points

A conservative original-space cost gate can merge suitable unassigned points into nearby finished components.

↓

Final clusters and outliers

Connected components become clusters; points that remain unsupported are labelled as outliers.

The two paths differ only in how the candidate-neighbour topology is obtained. The core cluster-growth and outlier decisions remain tied to the original feature space.

Install & Use

Install from PyPI and start clustering in 3 lines.

$ pip install deltric

Quick Start

from deltric import DelTriC
import numpy as np

# X: numpy array of shape (n_samples, n_features)
X = np.random.randn(500, 10)

# Auto-param mode — just pass your data
model = DelTriC()
labels = model.fit_predict(X)

n_clusters = len(set(labels) - {-1})
n_outliers = np.sum(labels == -1)
print(f"Found {n_clusters} clusters, {n_outliers} outliers")

Advanced Usage

# Force PCA projection, tune pruning
model = DelTriC(
    dim_reduction="pca",
    prune_param=1.3,
    anomaly_sensitivity=0.3,
    min_cluster_size=10,
    random_state=42,
)
labels = model.fit_predict(X)
print(model._last_auto_params())

In a scikit-learn Pipeline

from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

pipe = Pipeline([
    ("scale", StandardScaler()),
    ("cluster", DelTriC(dim_reduction="pca")),
])
labels = pipe.fit_predict(X)
